功能特性Features

三视图实时脑电3-view live EEG

原始波（四通道独立分框）· 频谱（1–60 Hz dB）· 光谱图（瀑布热图），一键切换。

Raw (4 independent lanes) · spectrum (1–60 Hz dB) · spectrogram (waterfall), one-tap switching.

电极质量与电量Electrode quality & battery

每通道 好/中/差 + 佩戴检测；电池图标按 60/20 分档变色，RSSI 信号强度实时显示。

Good/fair/poor per channel + wear detection; color-tiered battery icon and live RSSI.

Mind Monitor 兼容 CSVMind Monitor compatible CSV

EEG 256 Hz、加速度/陀螺 52 Hz、PPG/光学 64 Hz、电量与 HSI 列，MATLAB 脚本可直接读取。

EEG 256 Hz, accel/gyro 52 Hz, PPG/optics 64 Hz, battery and HSI columns — reads directly with MATLAB scripts.

事件标注Event markers

总览 4 键 + 记录页 9 键（长按改名）+ 自定义文本；断线/恢复自动写入标记。

4 quick keys + 9 renameable keys + custom text; automatic disconnect/reconnect markers.

长时间稳定采集Long-session stability

前台服务 + 唤醒锁（锁屏不断流）、数据看门狗、指数退避自动重连、GATT 缓存清理。

Foreground service + wake lock, data watchdog, exponential-backoff auto-reconnect, GATT cache refresh.

双协议 · 双语 · 深色模式Dual protocol · bilingual · dark mode

自动识别 Muse S Gen 2（Athena）与旧款 Muse；界面/日志随语言切换；深色模式全面适配。

Auto-detects Muse S Gen 2 (Athena) and legacy Muses; UI/logs switch with language; full dark mode.

快速上手Quick start

  1. 从 Releases 下载 APK 并安装（允许未知来源）。
  2. Download the APK from Releases and install (allow unknown sources).
  3. 开启头环电源，在「连接」页扫描并选择设备（MuseS-XXXX）。
  4. Power on the headband, scan and select it (MuseS-XXXX) on the Connect page.
  5. 总览页确认四个电极质量为绿色后，点「记录」开始；点 1–4 插入事件标注。
  6. Check all four electrodes are green on the overview, tap "Rec" to start; tap 1–4 to insert markers.
  7. 文件保存在 Download/MuseRecorder/，应用内可分享到电脑。
  8. Files are saved to Download/MuseRecorder/ and can be shared from the app.
