# Privacy Policy / 隐私政策

**简体中文**

MuseRecorder（本应用）不申请 INTERNET 网络权限，**完全不联网**，不收集、不上传、不共享任何用户数据。

- 脑电与传感器数据仅写入设备本地的 `Download/MuseRecorder/` 目录，由你全权掌控；可通过系统文件管理器随时查看、分享或删除
- 崩溃日志同样仅写入本地 `Download/MuseRecorder/`，仅在你主动发送给开发者时才会离开设备
- 应用不包含广告、统计 SDK 或第三方追踪组件（全部依赖均为界面与协程基础库）
- 设置（语言、预设事件等）存储于应用私有存储空间，卸载即清除

**English**

MuseRecorder does not request the INTERNET permission: the app never connects to the network and collects, uploads, or shares no user data whatsoever.

- EEG and sensor data is written only to the local `Download/MuseRecorder/` folder — you remain in full control and can view, share, or delete it at any time
- Crash logs are likewise written locally; they leave the device only if you choose to send them
- The app contains no ads, analytics SDKs, or third-party trackers (all dependencies are UI and coroutine libraries)
- Preferences (language, event presets, etc.) are stored in app-private storage and removed on uninstall

Contact: please open an issue at https://github.com/Shisi141414/MuseRecorder/issues
